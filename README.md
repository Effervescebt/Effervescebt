# Hi, I'm Haoru Li

I am an M.S. student in Machine Learning at **Carnegie Mellon University** (2026 - 2027). I received my
B.S. in Computer Engineering from the **University of Illinois Urbana-Champaign** with Highest Honors,
where I worked with Prof. Jiaxuan You on multimodal agents and temporal reasoning in LLMs, and with
Prof. Ying Diao on computer-vision pipelines for 3D-printed materials.

I work on LLM agents, post-training and multimodal reasoning, and on the systems that make them cheap
and fast to run. I enjoy building things from scratch and understanding how systems work at a
fundamental level.

Originally from **Nanjing, China**, I have a deep appreciation for all things cute, especially Kuromi. In
my spare time I play Monster Hunter and CS2, create with Blender, and play badminton. My lifelong
aspiration is to eat my way around the world.

## Featured work

| Project | What it is |
|---|---|
| [agent-harness](https://github.com/Effervescebt/agent-harness) | Tool-using LLM agent runtime. Shows that per-step context truncation made Claude Sonnet 5.5 4.5x more expensive by breaking the prompt cache, and that append-only checkpoint compaction cut that cost 62%. Self-hosted Qwen3-8B on vLLM with 92% KV-cache hits. |
| [internship-autopilot](https://github.com/Effervescebt/internship-autopilot) | Finds new internship postings twice a day, screens them for visa eligibility, and builds a one-page LaTeX resume for each. |
| [SeeingEye](https://arxiv.org/abs/2510.25092) (co-first author) | A 3B vision-language model passes structured visual evidence to an 8B text-only reasoner; 60.78% on MMMU, ahead of a 32B VLM. |
| [Time-R1](https://arxiv.org/abs/2505.13508) | Three-stage GRPO curriculum that lets a 3B model beat the 671B DeepSeek-R1 on future-event prediction. |
| [Unix-like OS kernel](https://github.com/Effervescebt/Computer-System-Design) | RISC-V kernel in C and assembly with Sv39 paging, a VirtIO block driver, an inode file system and 12 system calls. |
